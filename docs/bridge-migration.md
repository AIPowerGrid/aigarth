# Legacy bridge safety note

This topic concerns historical movement from the original AIPG proof-of-work
chain to the Base ERC-20. It is not the Grid inference transport.

Do not assume a legacy web wallet or bridge URL is operational. Do not quote a
processing time, fee, two-way capability, or deadline without a current official
source. Never ask for a seed phrase, private key, raw wallet file, or password.

For current migration help, send users to `https://aipowergrid.io` and the
official Discord support channel. The Base token they should independently
verify is `0xa1c0deCaFE3E9Bf06A5F29B7015CD373a9854608`.
