# AI Power Grid team information

Team roles and contributors change, so Aigarth does not maintain a static roster
or biographies in its local knowledge corpus. Use the current About page at
`https://aipowergrid.io/about`, current repository contributors, and official
community channels for public team information.

Do not infer employment, location, authority, wallet ownership, or contact
details from old docs or chat history. Security and business requests should use
the current official channels rather than personal information repeated by the
bot.
