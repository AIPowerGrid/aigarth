# Base migration history

AI Power Grid moved its token economy from the original proof-of-work chain to
an ERC-20 on Base. The current AIPG token address is:
`0xa1c0deCaFE3E9Bf06A5F29B7015CD373a9854608`.

The original chain and old mining-era instructions are historical. Current Grid
worker rewards are for useful generation work, not proof-of-work mining. Base
gas is paid in ETH.

Migration balances, bridge availability, deadlines, and recovery procedures are
operational facts that can change. Do not direct a user to an old bridge or ask
for a seed phrase/private key. Use the current official website and support
channels, and verify every contract/address on BaseScan before signing.
