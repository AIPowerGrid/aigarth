# AIPG token and network economics

AIPG is an ERC-20 on Base with 18 decimals and a fixed maximum supply of
150,000,000 tokens. Mint authority is reported as renounced. Token contract:
`0xa1c0deCaFE3E9Bf06A5F29B7015CD373a9854608`.

## Current network utility

- Bootstrap AIPG rewards are paid to worker accounts pro-rata by den.
- The Grid diamond uses AIPG-oriented registry and reward infrastructure.
- AIPG can be used in ecosystem products and liquidity venues supported by the
  project.

Passive staking rewards have ended. Worker bonding and validator staking are
future security mechanisms, not current requirements. Customer generation
credits and worker payout assets are separate accounting concepts; do not claim
that every API request directly spends AIPG.
